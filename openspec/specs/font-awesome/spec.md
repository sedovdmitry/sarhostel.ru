# Font-awesome Specification

> Generated by openlore v1.2.0 on 2026-11-09 16:38

## Purpose

Provides spinning and pulsing animation utilities for Font Awesome icons via the shared fa-spin
keyframes, with vendor-prefixed fallbacks.

## Requirements

> `font-awesome/scss/_animated.scss`

### Requirement: ApplySpinAnimation

The system SHALL apply a continuous linear 360-degree rotation animation to any icon element carrying the spin modifier class.

#### Scenario: SpinAppliedToIcon
- **GIVEN** An element with the fa-spin class
- **WHEN** The compiled stylesheet is applied
- **THEN** The element rotates from 0deg to 359deg every 2 seconds in an infinite linear loop
- **AND** A -webkit-animation equivalent is declared for older WebKit browsers

### Requirement: ApplyPulseAnimation

The system SHALL apply a stepped rotation animation (8 discrete steps) to any icon element carrying the pulse modifier class for a rotating-segments effect.

#### Scenario: PulseAppliedToIcon
- **GIVEN** An element with the fa-pulse class
- **WHEN** The compiled stylesheet is applied
- **THEN** The element rotates in 8 discrete steps per second in an infinite loop
- **AND** A -webkit-animation equivalent is declared for older WebKit browsers

### Requirement: DefineSpinKeyframes

The system SHALL define the fa-spin keyframes rotating from 0deg to 359deg, emitted twice (standard and -webkit- prefixed) for cross-browser support.

#### Scenario: KeyframesAvailableForBothPrefixedAndStandardAnimationProperties
- **GIVEN** The animated icons stylesheet is compiled
- **WHEN** An animation references the fa-spin keyframes
- **THEN** Both the standard and -webkit- keyframes rotate from 0deg at 0% to 359deg at 100%
- **AND** 359deg is used instead of 360deg to avoid visual stutter at the loop boundary

### Requirement: ApplyBorder

The system SHALL frame an icon with padding, a thin solid border, and a small border radius when the border modifier class is present.

#### Scenario: BorderAppliedToIcon
- **GIVEN** An element with the fa-border class
- **WHEN** The compiled stylesheet is applied
- **THEN** The element receives padding of .2em top, .25em sides, .15em bottom, a solid .08em border using
$fa-border-color, and a .1em border radius
- **AND** A -webkit-animation equivalent is declared for older WebKit browsers

### Requirement: ApplyPullFloats

The system SHALL provide global pull-right and pull-left float utilities for aligning icons (or any element) to the right or left edge of their container.

#### Scenario: ElementFloatedRight
- **GIVEN** An element with the pull-right class
- **WHEN** The compiled stylesheet is applied
- **THEN** The element is floated to the right
- **AND** A -webkit-animation equivalent is declared for older WebKit browsers

#### Scenario: ElementFloatedLeft
- **GIVEN** An element with the pull-left class
- **WHEN** The compiled stylesheet is applied
- **THEN** The element is floated to the left
- **AND** A -webkit-animation equivalent is declared for older WebKit browsers

### Requirement: ApplyPulledIconMargins

The system SHALL add directional margin spacing when a font awesome icon is also pulled left or right, so floated icons do not sit flush against adjacent content.

#### Scenario: IconPulledLeftGetsRightMargin
- **GIVEN** An element with both the base fa class and pull-left
- **WHEN** The compiled stylesheet is applied
- **THEN** A margin-right of .3em is applied
- **AND** A -webkit-animation equivalent is declared for older WebKit browsers

#### Scenario: IconPulledRightGetsLeftMargin
- **GIVEN** An element with both the base fa class and pull-right
- **WHEN** The compiled stylesheet is applied
- **THEN** A margin-left of .3em is applied
- **AND** A -webkit-animation equivalent is declared for older WebKit browsers

### Requirement: ApplyBaseIconStyles

The system SHALL style every element with the base fa class as an inline-block icon rendered with the fontawesome font at inherited font size, with antialiasing and half-pixel corrections applied.

#### Scenario: BaseIconRenderedInline
- **GIVEN** An element with the base icon class (fa-css-prefix)
- **WHEN** The compiled stylesheet is applied
- **THEN** The element is displayed inline-block with the shorthand font declaration 'normal normal normal
$fa-font-size-base/1 FontAwesome'
- **AND** A -webkit-animation equivalent is declared for older WebKit browsers

#### Scenario: IconInheritsSurroundingFontSize
- **GIVEN** An element with the base icon class inside a container with a custom font-size
- **WHEN** The compiled stylesheet is applied
- **THEN** font-size is set to inherit, overriding the shorthand font declaration so the icon scales with its
context
- **AND** A -webkit-animation equivalent is declared for older WebKit browsers

#### Scenario: CrossBrowserGlyphSmoothing
- **GIVEN** Any element with the base icon class
- **WHEN** Rendered in WebKit or Firefox/OS X browsers
- **THEN** -webkit-font-smoothing: antialiased and -moz-osx-font-smoothing: grayscale are applied, with
text-rendering: auto for consistent legibility
- **AND** A -webkit-animation equivalent is declared for older WebKit browsers

#### Scenario: HalfPixelRenderingFix
- **GIVEN** Any element with the base icon class viewed in Firefox
- **WHEN** The element is rendered
- **THEN** transform: translate(0, 0) is applied to avoid half-pixel rendering artifacts
- **AND** A -webkit-animation equivalent is declared for older WebKit browsers

### Requirement: ApplyFixedWidth

The system SHALL constrain any icon carrying the fixed-width modifier to a uniform computed width with centered glyph alignment.

#### Scenario: IconsAlignInAVerticalList
- **GIVEN** Multiple icons with the fa-fw class in a list
- **WHEN** The compiled stylesheet is applied
- **THEN** Each icon occupies an identical width of 18em/14 regardless of glyph metrics
- **AND** A -webkit-animation equivalent is declared for older WebKit browsers

#### Scenario: GlyphCenteredWithinFixedBox
- **GIVEN** An icon with the fa-fw class
- **WHEN** The compiled stylesheet is applied
- **THEN** text-align: center centers the glyph within the fixed-width box
- **AND** A -webkit-animation equivalent is declared for older WebKit browsers
