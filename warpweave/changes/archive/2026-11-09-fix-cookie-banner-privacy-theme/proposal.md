## Why

Cookie-баннер 152-ФЗ фактически не работает: uncss при старой сборке `styles/main.min.css` вырезал классы Bootstrap 3 (`navbar-fixed-bottom`, `alert`), поэтому `position: fixed` отсутствует и плашка рендерится статичным блоком в конце документа — ниже тёмного футера, на белом фоне, видна только на абсолютном дне страницы. Это нарушает существующее требование spec `personal-data-compliance` («уведомление в нижней части экрана»): посетитель при первом визите баннер не видит. Страница `/privacy/` при этом оформлена блёкло (светло-серый фон без выраженной «документальности») и не сочетается с тёмными секциями лендинга.

## What Changes

- **Баннер cookie**: замена обёртки `navbar navbar-default navbar-fixed-bottom` (классы вырезаны из сборки CSS) на собственный блок с `position: fixed; bottom: 0`; фон `#222` в стилистике футера `.bg-dark`, белый текст, flex-раскладка «текст + кнопка "Понятно"». Ссылка на Политику осветляется до `#5fc4b6` (контраст на `#222` ~8:1 вместо ~4.6:1 у `#44a69a`).
- **JS-логика согласия не меняется**: сохраняются `id="cookie_accept"`, класс `.btn` на кнопке и cookie `cookies_consent` на 30 дней ([index.php:795-803]).
- **Удаление мёртвых классов** `fade in` (правила вырезаны из сборки, классы ничего не делают).
- **`/privacy/`**: фон `body` → `#222` (как футер), белая карточка-документ с тёмным текстом остаётся без изменений — страница читается как юридический документ на тёмном фоне; `.footer-note` осветляется до `#95a5a6` (контраст на тёмном). Кнопка «Вернуться на главную» уже светлая (`btn-default`: белый фон из `main.min.css`) — правки не требует.
- **Удаление кнопки-дубля** «Политика конфиденциальности» после блока FAQ на главной ([index.php:726-729]) — каноничная ссылка остаётся в футере рядом с реквизитами ИП ([index.php:747]).

Правка устраняет несоответствие реализации существующему spec; позиционирование, цвет фона и оформление страницы `/privacy/` — презентационные детали без изменения поведения. ## Impact

- `index.php` — разметка баннера (~строки 760-770), добавление ~10 строк CSS в существующий инлайн `<style>`-блок head, удаление кнопки-дубля (~4 строки).
- `privacy/index.php` — инлайн-блок стилей: 1-2 строки (фон `body`, цвет `.footer-note`).
- JS не затрагивается; пересборка CSS (gulp/uncss) не требуется; новых зависимостей нет. Прекомпрессed `.br` для двух PHP-страниц — сервер regenerated при деплое по существующей конвенции.
